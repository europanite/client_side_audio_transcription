Client-Side Audio Transcription

A Browser-Based AI Audio Transcription Playground Powered by Whisper. No installation, registration, or payment required.

Runtime
Transformers.js + Whisper

Step 1 - Choose a model and media file

Pick a multilingual Whisper model, then select an audio or video file. Supported media is processed locally in your browser instead of being uploaded to a transcription backend.

Available Whisper models include Tiny, Base, and Small. The app supports automatic language detection as well as explicit language selection.

Step 2 - Model status

The selected Whisper model is loaded in the browser through Transformers.js. The interface reports loading, readiness, transcription, completion, and error states.

Step 3 - Transcription

The recognized text appears in the browser after transcription finishes. Audio decoding, model inference, and transcription run on the client.

Client-Side Audio Transcription is an open-source React, TypeScript, and Vite project using Whisper with Transformers.js.
